# Geo Arrow // Space Run

A frontend-only endless space runner for a school space and technology event.

## Run it locally

1. Install Node.js if it is not already installed.
2. Open this folder in VS Code or Cursor.
3. In the terminal, run:

```bash
npm install
npm run dev
```

4. Open the local URL Vite prints, usually `http://localhost:5173`.

## Controls

- Hold `Space` or `Arrow Up` to boost upward.
- Click/tap and hold the game area to boost.
- Release to drop between the hazards.

The run is one endless level with a 3-minute timer. Distance is measured in meters, and the hazard speed increases gradually as the flight continues.
